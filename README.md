## 📊 Proyek Unggulan

### 🛒 Market Basket Analysis Web App
> Aplikasi web analisis keranjang belanja yang di-*deploy* dengan **Streamlit**.

- Analisis dataset ritel online skala besar dengan **SQL & Python**
- **RFM Analysis** untuk segmentasi pelanggan (bernilai tinggi, loyal, dan berisiko churn)
- **Apriori Association Rules** untuk menemukan kombinasi produk dan strategi *bundling*
- Dashboard **Power BI** interaktif untuk monitoring penjualan & performa bisnis
- Deployment berbasis cloud agar insight dapat diakses real-time
